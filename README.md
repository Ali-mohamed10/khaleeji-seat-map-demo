# Khaleeji Tour Seat Map Demo

A standalone frontend prototype inspired by the Khaleeji Tour booking flow. Pick a table to see the seat count and price update, remove a selection, or reset the map. Sold-out tables are disabled.

## Run locally

Download `Khaleeji-Seat-Map-Demo.html` and open it in a browser. The demo uses HTML, CSS, and vanilla JavaScript. It runs offline with fictional seating and pricing, with no backend or payment integration.
